html

html 语法本身没什么好介绍的。本篇主要是记录一些写单 html 的开发经历。

2026+ 年，这种单 html 小玩具基本都是 AI 秒出，所以也没啥可以继续更新的内容。就当作是在 AI 时代之前的一些回忆吧。

单 html 的优点：

  • 对于比较简易的小玩意，写一个 html 单文件要比 GUI 应用简单很多。
  • 小
  • 跨平台
  • 快速部署（静态托管）或客户一键打开，无需依赖

缺点：

  • 跨域访问限制
  • 性能差，浏览器里跑运算密集单线程比本机 python 代码慢多了。
  • 比起框架，单 html 会比较麻烦。
