移动平台设置

拿到手机第一件事肯定是 root 啊..

before root

通用：

  • 开发者模式里，关闭绝对音量。关闭后，蓝牙设备自己的音量控制和手机本身的媒体音量是分开控制的，这样可以实现更加精细化的音频控制，或者是降低响度的上下限。这一点非常重要，因为 Android 权限一坨屎，很多软件都可以自己调整音量，在蓝牙耳机下擅自调整音量可能会损伤听力；而且我习惯了低音量，如果不关闭绝对音量，即使媒体音量调到最低我也无法接受。
    • ColorOS 15 将关闭绝对音量功能移除了，FUCK U ColorOS！

MIUI：

  1. 开启开发者模式
    • 在 USB 调试版块，该放行放行，该关闭关闭。
    • 在最下方关闭 MIUI 优化。MIUI 优化可能会导致无法使用 adb install 安装软件。（报错 INSTALL_FAILED_USER_RESTRICTED）顺带，这已经是一个持续至少 6 年的问题了。
      • 关闭后刷新率会自动 120HZ，调回 60。
  2. 使用 ADB 卸载一些包
    • com.miui.systemAdSolution：广告
    • com.miui.hybrid：快应用，杂种；为什么要卸载
    • com.sohu.inputmethod.sogou.xiaomi & com.iflytek.inputmethod.miui：自带的 搜狗 讯飞 输入法，我用 gboard
    • com.miui.newhome：内容中心，广告，好像不能卸载只能禁用
  3. 关闭 Github Mobile 的默认打开网址。Github Mobile 因 2FA 需要使用，但使用其查看项目确实非常智障。幸好 MIUI14 提供了设置应用默认打开的功能：长按应用 - 应用信息 - 默认打开，调为拒绝。

ColorOS：

  1. 开启开发者模式并设置：
    • 禁止权限监控，让你从某应用打开其他应用不需要确认

after root

通用：

  1. 模块与软件
  2. 不要在 Google Play 安装 QQ，无法开启深色模式。该信息可能过时。
  3. 见禁用软件。
  4. Google Play 可以通过蓝牙进行发送 - 接受软件，无需再次下载，不过只能传商店内的软件。
  5. Delta Chat 可以在源手机上点击 设置 - 添加第二台设备，然后用目标机扫码即可迁移单个账户。
  6. 可以在开发者选项里关闭 5G，减少耗电。
  7. 开启通话自动录音。

一加：

  1. ColorOS 原生支持更换应用名称与图标，可以规避审查。
    • 需要在 Google Play 安装 ColorOS 13 Icon pack / ColorOS Icons / ... （选择对应 Android 版本）
  2. LuckyTool 安装后在任务栏小部件有多出一些选项。
    • 极暗模式是好东西。
    • LuckyTool 可以开启 ColorOS 隐藏的不息屏模式，这在双机位笔试时非常有用。（LuckyTool - 功能 - 设置 - 启用息屏永不超时）

禁用软件

我使用 App Manager 进行软件的冻结操作。

scene5/6 也可以，但是其为闭源商业软件，操作麻烦，不用它。 雹 也可以，但是主要用于禁止日常应用后台运行；无法冻结某些系统应用。

以前我比较激进，会冻结几乎所有用不到的系统软件。现在为了稳定性已经比较佛系了，App Manager 打开把 运行中 的筛出来，随便冻结一些。

  • 注意：雹 的工作模式最好选择暂停。（强行停止的应用还会被其他软件唤醒，并且注册的通知进程也仍然会运行；隐藏的话，桌面图标会消失，我觉得不太方便）

禁用快应用中心

这是一篇久远的文章，是本页面中年龄最大的一篇。
快应用服务框架本意是好的，大家联合起来统一为一个标准，减少不必要的重复开发。（参考 browser）

但是到了现在，快应用已经成为了手机的毒瘤，垃圾的藏匿处。无数的广告弹窗在手机厂商纵容下疯狂攻击使用者。同时快应用服务框架本身违背了自由原则，无法在设置中卸载 | 禁用，只能收回权限，最多降低版本。为了您和家人的身心健康，建议禁用之：

  1. 查看快应用的包名：（例：MIUI 12.5）设置 - 应用设置 - 应用管理 - 找到 快应用服务框架 进入，点击右上角感叹号，查看应用包名。

    或：已知关键字可使用 adb shell pm list package [<keyword>] 在手机内以关键字查找包名。

    • MIUI 12.5：com.miui.hybrid 杂种，可能还有 .accessory 后缀
    • HarmonyOS：com.huawei.fastapp
    • ColorOS：com.nearme.instant.platform
    • vivo：com.vivo.hybrid
  2. 连接手机并开启 ADB 调试。
  3. 禁用包：adb shell pm disable-user com.miui.hybrid，也可以直接卸载，详情参考 ADB
