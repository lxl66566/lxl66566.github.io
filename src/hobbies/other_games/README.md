## 细说

### 动物井

**游玩动物井之前，不要看任何攻略！！！**（包含知识锁的）解谜游戏的一大乐趣就是学习到知识，理解作者设计的通畅感受。

动物井以程序体积小闻名。我之前看了一篇动物井程序解析的文章，觉得巨牛逼，我尊重作者的编程水平，于是买了这个游戏。（但是一直没玩，想玩还需要一个契机）

虽然我还没玩，但是我已经向我的舍友推荐了这个游戏，他开坑得比我要早，不过我初期比较投入，瞬间反超了他的进度。

后来，已经开坑的狗屎 galgame 太多了，实在让我没有玩下去的欲望，20260919 周六这一天我打开了许多狗屎 galgame 但是推一下就结束了，想着换换口味，就正式开坑了动物井。（从晚上 20 点开始玩，然后一抬头发现已经 24 点了，再一抬头就 02 点，哈哈）
